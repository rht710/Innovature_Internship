# Innovature - Month 4: Frontend Development with React

## Week 13: React Basics

This repository contains the work for Week 13, focusing on the fundamental building blocks of React and creating a modern, responsive user interface.

### 📚 Topics Covered
- **JSX Syntax**: Understanding the declarative UI pattern.
- **Components and Props**: Building reusable UI blocks and passing data efficiently.
- **CSS Modules & Inline Styles**: Implementing modular and scoped styling for components.

---

### 🚀 Assignment: Dashboard UI
The core project for this week is a **Dashboard UI** built with a focus on reusability and responsiveness. The dashboard serves as a central hub for stats, recent activities, and organizational announcements.

#### Key Features:
- **Modular Architecture**: Built using independent, reusable React components.
- **Responsive Design**: Fluid layout that adapts to various screen sizes.
- **Premium Aesthetics**: Clean design with subtle shadows, consistent spacing, and modern typography.

#### Core Components:
- `StatCard`: Displays key performance indicators with dynamic icon/color support.
- `RecentItems`: A list-based view of the latest activities or products.
- `Announcements`: A dedicated section for important updates and news.
- `Dashboard`: The main orchestrator layout that binds all components together.

---

### 🛠️ Tech Stack
- **Library**: React 18
- **Build Tool**: Vite
- **Styling**: CSS Modules & Inline Styles (as per curriculum requirements)
- **Icons**: Lucide-React (or similar modern icon set)

1. **Install Dependencies**:


