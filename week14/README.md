# 🚀 Week 14: Forms & State (React)

## 📌 Project Overview
Welcome to **Week 14: Forms & State (React)**! This week, we focused on React Forms and State management for the Innovature Frontend Development program.

The core objective was to build a modern, responsive, and dynamic multi-step registration form using React, demonstrating controlled components, form validation, and data persistence using browser local storage.

---

## 🛠 Project Features

### 1. Multi-Step Flow
Form is divided into 3 logical steps (Personal Info, Account Info, Review) to ensure a smooth user onboarding experience.

### 2. Form Validation
- **Client-Side Verification**: Real-time validation for required fields, email format, and password strength rules.

### 3. State Management
- **React Hooks**: Uses React's `useState` hook for handling complex form data and navigation state across multiple components.

### 4. Local Storage Integration
- **Data Persistence**: Saves partially filled form data to `localStorage` so users don't lose progress on page refresh.

### 5. Premium UI/UX
- **Modern Aesthetics**: Implemented with vanilla CSS using glassmorphism aesthetics, dynamic gradients, and smooth micro-animations.

---

## 📑 Tech Stack
- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (CSS Variables, Flexbox, Animations)

## 💻 Setup & Deployment

### 1. Prerequisites
Install all dependencies for the React application:
```bash

```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
