# Week 14: Forms & State (React)

This directory contains the Week 14 assignment for the Innovature Frontend Development program, focusing on React Forms and State management.

## 🚀 Assignment: Multi-Step Registration Form

The project is a modern, responsive, and dynamic multi-step registration form built using React. It demonstrates the use of controlled components, form validation, and data persistence using browser local storage.

### Key Features:
- **Multi-Step Flow**: Form is divided into 3 logical steps (Personal Info, Account Info, Review).
- **Form Validation**: Client-side validation for required fields, email format, and password strength rules.
- **State Management**: Uses React's `useState` hook for handling complex form data and navigation state.
- **Local Storage Integration**: Saves partially filled form data to `localStorage` so users don't lose progress on page refresh.
- **Premium UI/UX**: Implemented with vanilla CSS using glassmorphism aesthetics, dynamic gradients, and smooth micro-animations.

## 🛠 Tech Stack
- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (CSS Variables, Flexbox, Animations)

## 💻 Getting Started


2. **Run Development Server**:
   ```bash

   ```
