# Innovature Internship: E-commerce Backend Project

This repository contains the weekly progress and final deployment of the E-commerce Backend API developed during the **Innovature Internship to Hire Excellence Program (I2HEP)**.

## 📁 Project Structure

This repository is organized by weeks, covering the journey from basic Django setup to a full-scale cloud deployment.

### [Week 12: Cloud Deployment (Final)](./week12/) 🚀
*   **Deliverables**: [Live App](https://e-commerce-fqmn.onrender.com/api/products/), [Deployment Guide](./week12/DEPLOYMENT_GUIDE.md)
*   **Key Features**: Render Hosting, PostgreSQL Production DB, Environment Management, Automatic Migrations, and Wildcard Host Configuration.
